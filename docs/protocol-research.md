# Read-only protocol research

The native command surface remains the two documented printer IOCTLs plus fixed standard descriptor reads and Windows metadata. Unknown commands, unsupported GET_STATUS and captured command bytes cannot reach printer dispatch. Safety metadata is explicit; centralized authorization is enforced by UI execution and by the worker before enumeration/handle opening.

Protocol Explorer shows family, transport, requirements, exact host request description, expected response, reference, safety, availability, timeout and execution history. Select a previous execution in its history (or Communication Log), pin A, select B of the same command and compare. Execute repeats the selected documented operation; arbitrary replay is absent. Bytes changing between executions do not identify a historical error field.

`IProtocolModule` separates model compatibility, request framing description, response framing and response parsing. `ProtocolModules` registers analysis modules without GUI changes. `ResearchCommand` carries exact bytes, transport, models, response expectations, safety and evidence validation levels. Modules are analysis-only; registration cannot change `CommandRegistry` or authorize native traffic. Passive observation never establishes safe replay. No vendor module has been registered for PP-100 service commands.

Worker IPC uses newline-delimited WorkerReply JSON. Progress frames contain one completed native transaction; the final frame carries the result. The parent bounds stream size (32 MiB), individual frame size (16 MiB), frame count (4,096) and stderr (64 KiB). Worker calls are conservatively serialized across the application, including sibling interfaces. Timeouts stop the worker process tree; successful frames already delivered remain evidence. No missing response is fabricated. Handles are scoped to each worker operation and closed via SafeFileHandle/finally. PnP scans do not invoke the spooler.

Offline Evidence opens schema 2/3 ZIPs in a separate read-only workspace. Documents retain their original provenance and are labeled imported. No imported record becomes live state or executable traffic. Archive path/duplicate/size checks and raw evidence hashes are validated; a hash index is an integrity aid, not a digital signature. Older schema 2 bundles may lack hashes. No archive is extracted. Text documents larger than 16 MiB are omitted from display with a notice; raw files remain in the source ZIP.
