# Independent USBPcap fixture

`usb_u3v_sample.pcapng` is the public USB3Vision camera sample from the Wireshark SampleCaptures collection, downloaded unchanged 2026-10-22:
https://wiki.wireshark.org/uploads/__moin_import__/attachments/SampleCaptures/usb_u3v_sample.pcapng
Source listing: https://wiki.wireshark.org/SampleCaptures#usb-with-usbpcap-encapsulation

This is third-party camera traffic, not Epson hardware evidence. It contains 110 records, legacy three-stage control transfers and truncated video payloads. Keep original attribution with this fixture.

`usb_u3v_sample.tshark.tsv` was independently generated by TShark 4.2.6:

```
tshark -r usb_u3v_sample.pcapng -T fields -e frame.number -e frame.time_epoch -e usb.bus_id -e usb.device_address -e usb.endpoint_address -e usb.transfer_type -e usb.data_len -e usb.control_stage
```

Tests compare packet count, timestamps, bus/address, endpoint, transfer type and stages against this saved output. They also verify known setup bytes and legacy-stage reconstruction. This does not establish coverage of every USBPcap version or transfer type.
